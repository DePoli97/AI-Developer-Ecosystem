# Stay up to date

This repository grows incrementally — new articles, snippets, tutorials, and tools added regularly.

## Newsletter

A periodic digest of what has been added, plus notes on AI engineering patterns, devtools worth knowing, and occasionally something that did not make it into a full article.

**Subscribe on Substack:** coming soon.

In the meantime, the easiest way to follow along is to **watch this repository** on GitHub (click the Watch button, then select "All activity" or "Releases only").

## What gets published

- New articles in `articles/` — deep dives on RAG, safety, cost engineering, evals, and agent development
- New tutorials in `tutorials/` — step-by-step guides with runnable code
- New snippets in `snippets/python/` — focused, self-contained utilities for AI engineering tasks
- Strategic notes in `research/` — field notes on agent frameworks, AI devtools trends, and market observations

## RSS / Atom

GitHub provides an Atom feed for every repository. You can subscribe to commits via:

```
https://github.com/DePoli97/AI-Developer-Ecosystem/commits/main.atom
```

Add this URL to any RSS reader (Feedly, NetNewsWire, Reeder, etc.) to get notified of new content.
